# 空を飛んでみたニャ〜 🐈‍⬛
ZENStudy Webページコンテスト2026夏 応募作品


「Webアプリケーション開発1」で作成した恐竜ジャンプゲームをベースに、AIサポートを活用しながら制作したオリジナルのミニゲームです。

空飛ぶ黒猫を操作して、障害物を避けながら飛行距離1000mを目指します。

1000mに到達すると、特別なクリア映像が再生されます。

## GitHub Pages

https://nogyu-dev.github.io/flying-cat-game/

## 遊び方

- PC：スペースキーで上昇

- スマートフォン：画面をタップして上昇

- 障害物にぶつかるとゲームオーバー

- 1000mに到達するとゲームクリア

## 使用技術

- HTML

- CSS

- JavaScript

- AI（画像・動画生成、プログラミングのサポートに活用）

## 最後に

プログラミングコードを触って制作した、初めてのオリジナル作品です。

これまでの学習の成果を活かしつつ、自分なりのユーモアを詰め込みました。

ユニークで愛らしいイラストに加え、易しすぎず難しすぎない絶妙なゲームバランスの調整に特にこだわりました。

少しでも楽しんでいただけたら嬉しいです！
